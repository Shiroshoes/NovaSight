Help

Academic Affairs

This Help Center covers the tools available to Academic Affairs: uploading student grade data and reading the resulting dashboards and forecasts.

Upload File

Upload the official student grade Excel file from the Upload File page. NovaSight automatically processes the dataset, updates the database, and regenerates prediction results across every dashboard.

Accepted File

  • .xlsx (Microsoft Excel) only — .xls, .csv, and .xlsm are not accepted

Required File Name Format

Your file must be saved with this exact name pattern (spaces or underscores both work) or the upload will be rejected before processing even starts:

YYYY-N Student-Performance Dataset.xlsx

  • YYYY — the year the semester starts (e.g. 2024)
  • N — 1 for 1st semester, 2 for 2nd semester

Examples: 2024-1 Student-Performance Dataset.xlsx, 2024-2_Student-Performance_Dataset.xlsx

Sheet Layout Inside the File

Each sheet tab is one college (e.g. CAHS-SON, CBA, CCST), containing the program name, a semester/year header, and a repeating block per student: a row of subject codes followed by that student's row of grades. Files that don't follow this layout, or that are still open in another program, will fail to process even if the name is correct.

Dashboards

The Main Dashboard gives a campus-wide view across all colleges. Each college dashboard narrows every chart down to that college alone. Every dashboard has a mode toggle: Historical mode shows real, already-recorded data, while Prediction mode switches the same charts to NovaSight's forecast for future years — look for the dashed trend line and the "Predicted" label.

Chart Mode & Table Mode

Every dashboard has a 3-dot menu (⋮) in the top-right corner of the View Mode card. Chart Mode is the default visual view with charts and graphs; Table Mode swaps every chart for a plain data table showing the exact same numbers — useful for reading precise figures or copying data out of the dashboard. The KPI cards and the Model Performance card look the same in either mode.

Model Performance & Accuracy

Every dashboard includes a Model Performance & Accuracy card showing how well NovaSight’s underlying machine learning models are currently performing, using statistics such as R² and RMSE. Each model is labeled Trained, Skipped, or Error, so you can see at a glance whether a forecast on the page is backed by a reliable model or should be read with caution.

Common Issues

My Excel file won't upload.

Confirm the file is .xlsx, that the file name matches the required format exactly, and that it isn't still open in Excel.

No prediction appears after uploading.

Verify that the uploaded dataset contains complete student information and valid grades before processing. Predictions also need at least a few years of historical data to generate a reliable trend.

A chart shows a flat line or an unrealistic jump.

Forecast charts need enough historical years to detect a reliable trend. With only a few years of data, a forecast can look unusually flat or steep — this smooths out as more historical data is uploaded.

I can't log in.

Double-check your email and password, and confirm Caps Lock is off. If you still can't sign in, contact the system administrator to verify your account is active.

Need Assistance?

If the problem persists, please contact the NovaSight system administrator or the development team for further assistance.

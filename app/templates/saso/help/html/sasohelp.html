Help

SASO

This Help Center provides guidance for Student Affairs and Services Office in monitoring student performance, reviewing insights, and using NovaSight dashboards to support student development programs.

Chart Mode & Table Mode

Every dashboard has a 3-dot menu (⋮) in the top-right corner of the View Mode card. Chart Mode is the default visual view with charts and graphs; Table Mode swaps every chart for a plain data table showing the exact same numbers — useful for reading precise figures or copying data out of the dashboard. The KPI cards and the Model Performance card look the same in either mode.

Model Performance & Accuracy

Every dashboard includes a Model Performance & Accuracy card showing how well NovaSight’s underlying machine learning models are currently performing, using statistics such as R² and RMSE. Each model is labeled Trained, Skipped, or Error, so you can see at a glance whether a forecast on the page is backed by a reliable model or should be read with caution.

Student Insights

SASO users can access student performance insights to monitor academic trends, identify students who may need additional support, and assist in developing student intervention programs.

Available Information

  • Student performance summaries
  • Academic trend analysis
  • Student performance indicators
  • Prediction-based student insights

Dashboards

The SASO Dashboard provides a visual overview of student performance patterns. It helps users understand academic trends and identify areas where students may require additional support or intervention.

  • Historical Mode - Displays previously recorded student performance data.
  • Prediction Mode - Displays future performance forecasts generated by NovaSight.

Forecast charts use prediction indicators to separate estimated future outcomes from actual historical records.

Student Support Monitoring

NovaSight assists SASO in monitoring student performance patterns and identifying areas that may require academic guidance, support activities, or intervention programs.

  • Monitor student performance trends
  • Support student development programs
  • Assist intervention planning using data insights

Reports and Analysis

NovaSight reports summarize student performance trends and prediction results to help SASO evaluate student needs and develop appropriate support strategies.

Common Issues

No student insights appear.

Verify that your account has the correct access permissions and that student information is available in NovaSight.

Prediction results are unavailable.

Prediction requires enough historical academic data. Limited information may affect forecast generation.

The dashboard shows unexpected trends.

Forecast results are generated from historical patterns. Sudden changes in student performance may affect prediction results.

I cannot access my account.

Check your login credentials. If the issue continues, contact the NovaSight administrator.

Need Assistance?

If you encounter technical issues or need assistance understanding NovaSight insights, please contact the system administrator or authorized support personnel.

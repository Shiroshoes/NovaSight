This Help Center covers the tools available to MISO: uploading student grade data

Data Upload

Upload File

Upload the official student grade Excel file from the Upload File page, one file per semester. NovaSight cleans and stores each file, and once at least 6 semesters (3 school years) have been uploaded it retrains its prediction models and refreshes every dashboard automatically.

Accepted File

  • .xlsx (Microsoft Excel) only. The .xls, .csv, and .xlsm are not accepted

Required File Name Format

Your file must be saved with this exact name pattern (spaces or underscores both work) or the upload will be rejected before processing even starts:

YYYY-N Student-Performance Dataset.xlsx
  • YYYY - the year the semester starts (e.g. 2024)
  • N - 1 for 1st semester, 2 for 2nd semester

Examples: 2024-1 Student-Performance Dataset.xlsx, 2024-2_Student-Performance_Dataset.xlsx

Sheet Layout Inside the File

Each sheet tab is one college (e.g. CAHS-SON, CBA, CCST), containing the program name, a semester/year header, and a repeating block per student: a row of subject codes followed by that student's row of grades. Files that don't follow this layout, or that are still open in another program, will fail to process even if the name is correct.

After an Upload

  • A file that was already uploaded is detected as a duplicate.
  • When processing finishes, a training summary lists every model as Trained, Skipped or Error.
  • The more semesters you upload, the further ahead the Prediction Analysis charts can look.
Tips

Using NovaSight on a Phone or Tablet

On a tablet or phone the sidebar is hidden to give the dashboards more room. Tap the ☰ button in the header (or swipe right from the left edge) to open it; tap outside it, press ✕, or swipe left to close it.

Machine Learning

Model Training Results

After each upload, a training summary shows every model labeled Trained, Skipped (not enough data yet), or Error (the message explains what went wrong).

NovaSight is built for decision support, not evaluation. Predictions are meant to help flag student cohorts who may benefit from additional academic support. They are not a performance score for any college, department, or dean.

Troubleshooting

Common Issues

My Excel file won't upload.

Confirm the file is .xlsx, that the file name matches the required format exactly, and that it isn't still open in Excel.

I can't log in.

Double-check your email and password, and confirm Caps Lock is off. If you still can't sign in, contact the system administrator to verify your account is active.

Support

Need Assistance?

If the problem persists, please contact the NovaSight system administrator or the development team for further assistance.

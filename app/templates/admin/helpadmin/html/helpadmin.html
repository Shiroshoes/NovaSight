Help

Admin

This Help Center covers the Admin tools: creating and managing user accounts for NovaSight. Admin accounts do not upload grade data — that's handled by Academic Affairs.

Adding a User

From the Admin page, use the + button to open the Add User form. Fill in the user's name, account, and role, then set a password.

Password Requirements

  • 8–16 characters
  • At least one uppercase letter
  • At least one number
  • At least one special character (e.g. !@#$%^&*)

Use the Generate button next to the password field to create a password that already meets all requirements — it's revealed on screen so you can copy it before saving.

Editing a User

Click Edit on any user row to open their details. You can update their name, account, or role, and optionally set a new password — leave the password field blank to keep their current one.

Deactivating / Activating a User

Open a user's Edit form to Deactivate their account — they won't be able to log in until an admin Activates it again. Deactivated users are listed separately and can be restored the same way.

Dataset Format Reference

Admin accounts don't upload grade data themselves, but can view and download the required format below — useful for verifying a file before it goes to Academic Affairs, or helping troubleshoot a failed upload.

Required File Name Format

YYYY-N Student-Performance Dataset.xlsx

  • YYYY — the year the semester starts (e.g. 2024)
  • N — 1 for 1st semester, 2 for 2nd semester

Only .xlsx files are accepted — .xls, .csv, and .xlsm are not. Each sheet tab is one college, laid out as a program name, a semester/year header, and a repeating block per student: a row of subject codes followed by that student's row of grades.

Dashboards

Admin accounts can also view the Main Dashboard and each college dashboard. Every dashboard has a mode toggle: Historical mode shows real, already- recorded data, while Prediction mode switches the same charts to NovaSight's forecast for future years.

Profile

Manage your own account information, update your profile picture, and change your password from the Profile page.

Common Issues

The password field won't accept my input.

Passwords must be 8–16 characters and include at least one uppercase letter, one number, and one special character. The field border turns red when a requirement isn't met yet, and green once it is.

I can't find a user I deactivated.

Deactivated accounts move to the archived/inactive list rather than staying in the main user list. Open that list to find and reactivate them.

My changes to a user didn't save.

Check that every required field is filled in and, if you entered a new password, that it meets all password requirements above.

I can't log in.

Double-check your email and password, and confirm Caps Lock is off.

Need Assistance?

If the problem persists, please contact the NovaSight development team for further assistance.
